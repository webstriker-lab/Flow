# Meta Skills

Repository onboarding, continuous environment hardening, skill authoring, and session diagnostics.

## User-invoked
- [`setup`](./setup/SKILL.md) — One-time per-repo setup (`.gitignore`, `AGENTS.md`, `docs/adr/`, `playwright-cli` check, optional `/create-verification-skill`).
- [`retro`](./retro/SKILL.md) — Post-session repo/agent environment improvements + `verify-<app>` drift check.
- [`diagnosing-flow`](./diagnosing-flow/SKILL.md) — Transcript-based debugger when a Flow skill misfires or gets skipped.

## Model-invoked
- [`writing-for-agents`](./writing-for-agents/SKILL.md) — Guide for writing skills, `AGENTS.md`, and agent-read docs (includes skill-testing checklist).
