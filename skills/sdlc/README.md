# SDLC Skills

Core Two-Gate engineering pipeline: Gate 1 alignment (`/grill-with-docs`) → autonomous worktree, planning, TDD, proactive deep-module architecture (`codebase-design`), automated review, and PR drafting → Gate 2 human review before push/merge (`finishing-a-development-branch`).

## User-invoked
- [`flow`](./flow/SKILL.md) — Route to the right Flow skill for your current situation.
- [`grill-with-docs`](./grill-with-docs/SKILL.md) — Gate 1 relentless design-tree grill + `GLOSSARY.md`/ADRs + spec handoff.

## Model-invoked
- [`using-flow`](./using-flow/SKILL.md) — Session bootstrap: Two-Gate contract and write-ahead `STATE.md` checkpointing.
- [`domain-modeling`](./domain-modeling/SKILL.md) — Shared vocabulary, `GLOSSARY.md`, and ADR maintenance.
- [`codebase-design`](./codebase-design/SKILL.md) — Deep-module vocabulary and proactive architectural deepening during development.
- [`using-git-worktrees`](./using-git-worktrees/SKILL.md) — Isolated feature worktree and clean test baseline.
- [`writing-plans`](./writing-plans/SKILL.md) — Bite-sized TDD implementation plans (`docs/flow/plans/`).
- [`subagent-driven-development`](./subagent-driven-development/SKILL.md) — Fresh subagent per task + two-stage review + whole-branch final review.
- [`executing-plans`](./executing-plans/SKILL.md) — Inline single-context plan execution fallback.
- [`dispatching-parallel-agents`](./dispatching-parallel-agents/SKILL.md) — Concurrent subagents for independent tasks.
- [`test-driven-development`](./test-driven-development/SKILL.md) — Strict RED-GREEN-REFACTOR discipline.
- [`systematic-debugging`](./systematic-debugging/SKILL.md) — 4-phase root-cause debugging loop.
- [`requesting-code-review`](./requesting-code-review/SKILL.md) — Automated spec, quality, and architecture review.
- [`receiving-code-review`](./receiving-code-review/SKILL.md) — Disciplined response to review findings.
- [`pr`](./pr/SKILL.md) — High-signal PR body (visual Summary, Evidence, Merge Danger).
- [`finishing-a-development-branch`](./finishing-a-development-branch/SKILL.md) — Gate 2 pause before push/merge with verified diff, proof, and PR draft.
